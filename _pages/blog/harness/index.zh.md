我在研究不同领域的 agent harness 有哪些差异，以及其中哪些机制可以迁移到其他领域。这份整理记录了我对相关工作的阅读和比较。

## 专题

1. [Coding](/blog/harness/coding/)：完成具体任务的内环，以及持续改进 Harness 的外环。
2. [Auto-Research Harness](/blog/harness/auto-research/)：从文献调研、想法筛选到实验和论文写作。
3. [EDA（探索性数据分析） Harness](/blog/harness/eda/)：从数据和问题出发，组织分析并形成可用的洞察。
4. [量化金融 Harness：研究闭环、交易链路与证据边界](/blog/harness/quantitative-finance/)：区分可执行研究、历史模拟和真实交易的证据。
5. [Coding RSI Harness 从失败修复到下一轮更会改进](/blog/harness/coding-rsi/)：从修复当前任务，到改进产生下一轮改进的方法。
